# 仓储功能完整测试报告

报告日期：2026-09-18
测试环境：本地 PostgreSQL、API `http://127.0.0.1:3001/api`、Web `http://127.0.0.1:5173`
测试数据：持久化 `TEST-FUNC-*`；最新 API 功能运行：`TEST-RUN-20260918094924`

## 1. 结论

本轮已完成原报告中列出的 P0 补测。仓储工作台的库存变更仍经由“库存单据 → 提交审批 → 同事务过账 → 库存流水”完成；API 功能运行、页面自动化、余额/流水对账均通过。

结论是：**本地 P0 验收通过，P1 的本地桌面与 390px 视口基线通过。** 这不替代生产数据量、真实移动设备、浏览器/缩放矩阵和线上权限配置验收。

| 不良品仓常规操作 | 不良品仓仅展示库存/风险，入口进入不良品处置 | 符合独立处置模型；不开放常规入、出、移、盘点 |
