## 本次代码准备

- 原材料明细的物料、数量和备注字段提供可访问标签；批量入口和明细逐行审批功能由健康接口 `features.batchInbound` 控制，环境变量未设为 `true` 时默认关闭。
- 批量导入增加文件 SHA-256 幂等请求；同一文件以同一幂等键重试返回原结果，新的键表示新的一次导入。
- 逐行审批只接受显式 `APPROVE` / `REJECT`，约束请求大小和字段格式；过账后通过库存流水与状态保护避免旧整单接口或并发重试重复过账。
- 局部审批保留已处理明细的分配；待审明细的容量仍继续预留。审核界面保留正常品/不良品分配，按选中明细过账；隔离 E2E 验证该路径生成两条库存流水、缺陷批次和审批审计。
- 内部异常仍记录在服务器日志，HTTP 500 只向客户端返回通用信息。
- `Dockerfile.api` 启动时只启动服务；迁移与种子操作从生产 API 启动流程分开。开发 Compose 保留本地迁移/种子步骤。
- 固定版本镜像发布工作流不再推送可变 `latest` 标签。候选双副本 Compose 只把 Web 发布到服务器回环端口，不发布数据库端口，并复用外部既有数据库、网络和上传卷。

## 数据库迁移步骤

迁移 `1990000000000-MaterialInboundLineReview` 增加 5 个审核字段、检查约束和 `(document_id, review_status)` 索引。生产发布前用新镜像中的在线准备脚本先补齐字段、以 `NOT VALID` 添加约束后验证，并用 `CREATE INDEX CONCURRENTLY` 建索引。锁等待上限为 2 秒；遇到锁竞争会失败退出，可在确认无竞争后重试，不会终止现有会话。随后单独执行应用迁移器一次；API 副本启动不再并行执行迁移。

推荐运行顺序：

1. 部署准备版镜像，在现有库存网络内启动一个限资源候选副本，`BATCH_INBOUND_ENABLED=false`。
2. 由候选 API 执行 `node dist/database/prepare-batch-inbound.js`，检查在线 DDL 结果。
3. 由单一发布执行者运行 `node dist/database/run-migrations.js`。检查迁移记录和索引有效状态。
4. 通过兼容性检查后切换 Web 代理到准备版。旧 API 停止接收新请求、在途请求结束后，再运行 `node dist/database/prepare-batch-inbound.js --backfill-legacy`，逐批补齐历史已过账原材料明细；检查残留数量为 0。
5. 启动同一代码和镜像摘要、`BATCH_INBOUND_ENABLED=true` 的功能版候选实例，通过健康、登录、查询和业务验证后再切换入口。

每批历史修正最多更新 1000 行，并只将历史 `POSTED` 原材料入库的 `PENDING` 明细标记为已过账。不得篡改已应用的历史迁移。任一步遇到锁超时或资源不足即停止，不终止业务连接。

## 候选部署配置

`docker-compose.batch-inbound-candidate.yml` 是模板。运行前必须从本次只读服务器检查确认 Docker 网络名、上传卷名、数据库服务 DNS 名、镜像摘要及可用端口；不得从历史文档猜测。它要求使用现有应用数据库凭据，但模板不保存值。API 不映射宿主机端口；候选 Web 只绑定 `127.0.0.1:18081`。

API 限制为 0.5 CPU / 512 MiB，Web 为 0.25 CPU / 256 MiB。ECS 目前的历史规格为 2 vCPU / 2 GiB，尚未核实当前占用和剩余磁盘，因此这些上限不是资源通过证明。候选启动后若内存、CPU、磁盘或并行请求验收不通过，立即停止候选并保持原站点。

部署前还要人工检查当前 1Panel/OpenResty 站点代理的实际配置文件和生效上游。先复制原配置，再只改库存站点上游，运行配置测试并平滑重载；不得影响 CRM、服装库存和其他站点。旧版本至少保留到回滚窗口结束，并确认前端静态资源仍可供旧页面访问。

## 备份与隔离恢复

生产备份尚未在本次任务中创建或恢复。实施前必须使用受保护目录新建数据库一致性备份，记录数据库标识、时间、文件大小和 SHA-256，使用 `pg_restore --list` 检查归档，并将备份恢复至隔离 PostgreSQL 后核对表数、关键约束和只读查询。备份文件及日志不得含密码或连接串。同步保存上传目录、部署配置、当前容器镜像摘要和代理配置副本。失败或不完整时停止发布。

整库恢复不作为普通代码回滚。生产数据一旦包含新操作，只能切换到理解逐行状态的兼容版本，关闭新入口并安全处理在途单据。
