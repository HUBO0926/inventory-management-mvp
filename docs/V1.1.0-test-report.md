| INV-110-001 | 高 | 编辑物料携带隐藏字段时报 DTO 错误 | 前端整体回传表单，后端 DTO 不接受身份字段 | 前端显式白名单；后端按引用情况允许身份字段 | 类型检查、E2E |

| INV-110-004 | 高 | 全新库种子执行失败 | PostgreSQL 参数类型推断冲突 | 拆分参数并显式类型 | 全新迁移与种子 |
